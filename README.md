**# AirMouse**
# 📥 Download the App
[![Download setup.exe](https://shields.io)](https://github.com/ima3dsoftwareuser/AirMouse/releases/download/1.0.0/AirMouseSetup.exe)


**AirMouse is a Windows application that lets you control your computer using hand gestures, voice commands, and camera-based tracking.**



**## Features**



**-  Hand gesture controls**

**-  Camera-based AirMouse cursor control**

**-  Virtual trackpad**

**-  Voice commands**

**-  Cursor movement and control**

**-  Custom voice commands**

**-  Configurable settings**

**-  Shared camera server architecture**

**-  Windows installer for easy installation**



**## Installation**



**### Using the installer**



**Download the latest `AirMouseSetup.exe` from the GitHub Releases page.**



**Run the installer and follow the setup instructions.**



**After installation, launch:**



**`AirMouseLauncher.exe`**



**### From source**



**Clone or download this repository and make sure Python and the required dependencies are installed.**


Requirements

AirMouse is designed for Windows.

Running the source code requires Python and the Python packages used by the project.

The recommended way for normal users to run AirMouse is through the provided Windows installer.

Releases

Pre-built Windows releases are available through the GitHub Releases page.

The installer contains the required application components and installs AirMouse as a complete application.
